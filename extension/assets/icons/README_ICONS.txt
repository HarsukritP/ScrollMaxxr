Icon Placeholders

You need to add three icon files here:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

You can:
1. Create icons using a design tool (Figma, Photoshop, etc.)
2. Use an online icon generator
3. Use AI to generate an icon (DALL-E, Midjourney, etc.)

Recommended design: A target/bullseye icon with purple gradient to match the brand colors (#8b5cf6 to #ec4899)

For now, you can use any PNG files renamed to these names to test the extension.
